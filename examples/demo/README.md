# Demo: reproduce the README numbers

Everything here is generated offline from the bundled Manifold sample and
the compressed-bias fixture. No network, no API keys.

```bash
pip install -e .
./run.sh            # or: longshot demo --outdir examples/demo
```

Artifacts (all regenerated by the command above):

- `analysis_bundled.json` — full calibration/bias analysis of
  `data/bundled/manifold_resolved_sample.jsonl` (278 real resolved
  Manifold markets; see `data/bundled/SOURCES.md`).
- `correction_bundled.json` — Platt/isotonic corrections fit on the
  earliest 60% of markets by resolution date, evaluated on the rest.
- `report_bundled.html` — self-contained report (inline SVG, no JS).
  `report_bundled.json` is a JSON sidecar of the same analysis.
- `analysis_biased_fixture.json` — same pipeline on
  `fixtures/biased_markets.jsonl` (simulator output with planted
  compression 0.55; the measured 30d slope ~1.8 = 1/0.55 is the recovery
  check).
- `run_output.txt` — captured stdout of the demo run committed here.
