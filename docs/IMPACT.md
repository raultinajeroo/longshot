# Impact

What is actually known about this project's usage and effect. Written
deliberately conservative: if a number is not listed here, we do not have
it.

## Metrics that ARE collected

- **CI status.** Test pass/fail on GitHub Actions, visible on the commit
  history and PR checks. That is the only automated signal.
- **Repository traffic.** GitHub's built-in traffic view (clones, views)
  is available to the owner, but is not tracked, archived, or published.

## What is NOT collected or known

- **No usage telemetry.** The tool reports nothing anywhere; there is no
  way to know how many times it has been run, by whom, or on what data.
- **No adoption numbers.** No known users, teams, or organizations using
  this anywhere. Any such claim would be fabrication.
- **No forecasting skill claims about real money.** The only real-venue
  numbers in this repository come from the bundled sample of 278
  play-money (Mana) Manifold markets under `data/bundled/`. They are a
  methodology demonstration on one venue, one fetch date, one sample; they
  are not claims about real-money venues or about any future market.
- **No trading outcomes.** longshot is read-only: it places no orders,
  so there are no profits, losses, or fills to report. Nothing it
  produces is investment advice.

## How impact would be evidenced

If this ever changes (e.g. someone reports using it), evidence would be a
link to a public issue, discussion, or write-up — not a self-reported
number.
